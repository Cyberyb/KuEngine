# 2026-08-25

为公共统计面板加入业务绘制数量及 CPU/GPU 时间，覆盖四个示例的统一绘制入口。

- RHI：CommandList 增加 draw/drawIndexed 计数和 Timestamp Query；RHIDevice 暴露图形队列时间戳能力。
- Core：采集 CPU 时间，在 Fence 完成后读取 GPU 时间并传给 UI。
- UI：显示 FPS、Frame、CPU、GPU、Draw Calls 和 Vertices；计时无结果时显示 N/A。
- Render/Examples：PBR、Skybox、Triangle、Cube、Alpha3Pass 改用带计数的绘制接口。
