# Bug 记录

每个需要持续追踪的问题使用稳定主题文件名，例如 swapchain-resize.md；在同一文件内维护复现、根因、修复和回归结果，格式见 [template.md](template.md)。

发现问题时写明环境和实际现象；确认修复后补充具体行为变化和验证结果。临时猜测要标为待确认，不写成已证实根因。

修复影响模块行为时同步 [design](../design/README.md)，完成摘要记入 [当日日志](../logs/README.md)，用户操作变化同步 [usage](../usage/README.md)。后续开发目标写入 [structure](../structure/roadmap.md)。
